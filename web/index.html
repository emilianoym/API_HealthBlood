LA API
JUEGA EN
GRANDE.

Una estructura de ejemplo para conectar aplicaciones con un servicio de registros de glucosa.

POST/api/glucosa/registrarMedida
GET/api/glucosa/getMedidas?idUsuario=1
GET/api/glucosa/getUltimaMedida?idUsuario=1
GET/api/glucosa/getAllUsuarios
📄 EJEMPLO · JSON
{
  "id_usuario": 1,
  "glucosa_mg_dl": 108,
  "fecha_hora": "2026-10-26T08:30:00",
  "contexto": "ayuno"
}

* Los POST reciben application/x-www-form-urlencoded. Para /api/glucosa/registrarMedida, id_usuario y glucosa_mg_dl son obligatorios; fecha_hora y contexto son opcionales.

POST /api/glucosa/registrarUsuario: nombre (obligatorio), primer_apellido, segundo_apellido y email (opcionales).
